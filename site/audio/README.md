# TURK music

Put the two music files in this folder, named exactly:

- `turk-lobby.mp3` — plays in the lobby and on the round summary
- `turk-table.mp3` — plays while a round is being played

They're served as `/audio/turk-lobby.mp3` and `/audio/turk-table.mp3`.
If either file is missing, the game still works and the music button shows "Music unavailable".
Keep each file under ~5 MB (128–192 kbps MP3 is plenty). Use tracks you own or have a licence for.
